# NER Text to Speech v1.0.0

Rilis pertama aplikasi text-to-speech berbasis Web Speech API.

## Isi rilis

- `index.html` — aplikasi lengkap (HTML + CSS + JavaScript)
- Kontrol bicara / jeda / lanjut / stop
- Pilih suara, bahasa, kecepatan, dan pitch
- Antarmuka bahasa Indonesia

## Cara pakai

Unduh `index.html` di bawah, lalu buka di Chrome, Edge, atau Firefox.
